## 답 · 2026-11-18 10:19 · unverified

Start with folder input and saved lists, then redesign the frontend around how people open and revisit manga. Build the Windows `.exe` from that version and finish the Korean README against the launcher and screens people will actually use. All five tasks belong in the plan.

The existing Android and Windows apps already open a manga URL, draw Korean dialogue over the page images, and keep translated pages for export. The home screen remembers the five most recent URLs. That gives the new work a starting point, but a recent address and a translated image serve different purposes from a collection someone deliberately saves.

| Order | Task | What should count as done |
|---|---|---|
| 1 | Open a folder alongside a URL | On Windows and Android, a reader can select a folder and read its images in natural filename order, so `2.jpg` comes before `10.jpg`. Reopening identical image bytes in the same source language reuses the saved translation, including when the image was first read from a link. |
| 2 | Add saved lists for both sources | Follow the useful parts of `video-translate-overlay-2`: find a title again without remembering its address, group it into named lists, reorder entries, and reopen it after restarting the app. One title can belong to several lists. Removing it from a list preserves its translations. Existing translated books remain accessible and exportable. |
| 3 | Rebuild the phone and PC layouts | The current app uses the same bottom navigation and a 960 CSS-pixel maximum content width on both. On the Galaxy S21, keep navigation within thumb reach and expand a selected list in place. At 1920 × 1080 on Windows, keep lists visible on the left and show the selected list’s titles on the right, with search and link/folder input above. Verify that someone can open, save, find, and reopen a title on each device. The installed apps are the acceptance targets for reading. |
| 4 | Deliver a working Windows `.exe` | Windows bundling is configured. The deliverable is an executable someone can double-click on a machine without the development checkout, then use to open both a link and a folder. |
| 5 | Rewrite `README.md` for Korean readers | Lead with how to start the app and read the first chapter. Use short Korean sentences, the exact labels shown on screen, and separate instructions for Windows and Android. Explain saving a source, reusing a translation, and exporting images where each action occurs. Put developer setup after the reader guide. |

One behavior needs an explicit decision. In `video-translate-overlay-2`, opening a saved title and starting paid translation are separate actions. This manga reader currently translates new images automatically as they come into view. Saving or organizing a title should make zero Gemini requests under either approach.
