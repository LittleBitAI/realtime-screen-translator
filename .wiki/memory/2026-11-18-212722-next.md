# All five planned tasks delivered and merged (PRs #3, #4, #6, #7, #8): folder import, saved lists, phone/PC redesign, Windows installer, Korean README

The user asked for the next work and named five required tasks: rewrite README.md for Korean readers, build a PC launcher (.exe), add saved lists modeled on the playlists in video-translate-overlay-2, accept folders as input as well as links, and redesign the frontend for mobile and for PC at 1920 × 1080. The user then chose one-chapter folders, imported copies, translate-while-reading and an installer EXE. All five tasks were delivered in this order: folder import (PR #3), saved lists (PR #4), phone/PC layouts (PR #6), Windows setup .exe (PR #7) and the Korean README (PR #8). Every PR passed its completion criteria and was merged; PR #7 merged with one P2 still open.

## Decisions

- A folder input is imported as one chapter
- Folder images are imported as an app-owned copy rather than read in place — The reader can still open the chapter after the original folder moves, at the cost of device storage
- Translation starts automatically as the reader approaches a new page; saving, importing or organizing a title makes zero Gemini requests (rejected: Separate open and start-paid-translation actions, as in video-translate-overlay-2)
- The Windows deliverable is an installer (setup) EXE

## Facts

- PR #3 lets a reader on Android or Windows open a manga URL or import one image folder as a chapter and read the app-owned copy. It passed 6 completion criteria and merged in round 6 with 0 remaining P2.
- PR #4 lets readers find manga again and organize links and imported chapters into persistent named lists. It passed 6 completion criteria and merged in round 5 with 0 remaining P2.
- PR #6 makes the app usable for opening, organizing and revisiting manga on a Galaxy S21 and in a 1920 × 1080 Windows workspace. It passed 5 completion criteria and merged in round 2 with 0 remaining P2.
- PR #7 lets a Windows user install the integrated manga reader from a setup .exe and launch it without a development checkout. It passed 4 completion criteria and merged in round 2 with 1 remaining P2.
- PR #8 rewrites README.md so a Korean-speaking first-time reader can install the app, read a chapter and find it again. It passed 6 completion criteria and merged in round 3 with 0 remaining P2.
- Before this work, the Android and Windows apps opened a manga URL, drew Korean dialogue over page images, kept translated pages for export, and remembered the five most recent URLs on the home screen (unverified)
- Before PR #6, phone and PC used the same bottom navigation and a 960 CSS-pixel maximum content width (unverified)
- Planned folder behavior: images are read in natural filename order (2.jpg before 10.jpg) (unverified)
- Planned folder behavior: identical image bytes in the same source language reuse an existing translation, even if first read from a link (unverified)
- Planned saved-list behavior: one title can belong to several lists, entries can be reordered, and removing a title from a list keeps its translations (unverified)
- Planned layout: on PC, lists are shown on the left and the selected list's titles on the right, with search and link/folder input above; on phone, navigation stays within thumb reach and a selected list expands in place (unverified)

## Preferences

- README.md should be up to date and written in sentences that are easy for Korean readers to read
- Saved lists should follow the same philosophy as the playlists in video-translate-overlay-2
- Input should accept a folder as well as a link
- Mobile and PC layouts should differ, worked out using design skills to the fullest; the PC version targets 1920 × 1080
