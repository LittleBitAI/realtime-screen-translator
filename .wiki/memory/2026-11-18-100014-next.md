# PR #1 browser-based realtime screen translator (Japanese manga → Korean, mobile-first) and PR #2 wiki init both merged

PR #1 built a realtime screen-recognition translator that runs in the web browser so it works on both mobile and PC. Mobile optimization comes first, with Galaxy S21 as the reference device. PR #1 passed 3 completion criteria and was merged after round 11 with 2 P2 items remaining. PR #2 initialized the repository wiki, passed 1 completion criterion, and merged in round 1 with 0 P2 remaining.

## Decisions

- Deliver the translator as a web-browser app usable on both mobile and PC — So the program can be used on both mobile and PC
- Prioritize mobile optimization, using Galaxy S21 as the reference device — Mobile is the most-used platform
- Primary use case is realtime translation of Japanese manga into Korean; track vertical scroll and horizontal sliding page turns (previous/next page) separately
- Do not re-translate text already translated, and do not translate sound effects (효과음)
- Use Gemini 3.1 Flash Lite as the translation model, with default safety guardrails turned off and a prefill added
