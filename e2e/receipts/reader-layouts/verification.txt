  fresh store. Both returned 200 with empty arrays. POST /library/edit

  searching by title returned one row with the exact title and URL.
  A new list returned no books. The original book appeared in each
  selected list after being added to both. Removing its first membership
  returned that list to empty. Deleting the empty list left the other
  membership in place. Filtering by the title
  or by the encoded address each returned the original book ID and URL.
  An unmatched query returned no books. GET /status reported 0 model
  requests.

  The export scenario used two synthetic books. POST /books/1/export
  returned 200 for PNG and WebP, with one file matching the response
  count for each. GET of each returned file yielded 200, the expected
  format signature, bytes equal to the file written, and an attachment
  header. GET /status reported 0 model requests.
